# Роли и доступ

Платформа различает роли на уровне платформы и роли внутри проекта.

## Роли платформы

| Роль | Что доступно |
|---|---|
| Гость | Каталог и три демо-проекта. Демо живут в браузере. Создать свой проект гость не может. Расчёт и выгрузка PDF и XLSX идут через API и не пишут коммерческие данные в базу и в журналы |
| Пользователь | Свои проекты: создание, правка, копирование, удаление, расчёт, симуляция, экспорт |
| Администратор | Всё, что у пользователя, и вкладка **Админ**: каталог, нормативы, приглашения, журнал |

Демонстрационные учётные записи создаются при старте API, если записей с такими адресами ещё нет. Адреса и пароли приведены в разделе [Развёртывание](guide/02-install.md#демонстрационные-учётные-записи). Перед любой публикацией в сети пароли нужно сменить, см. [Сопровождение](operations.md).

## Роли в проекте

| Роль | Что доступно |
|---|---|
| Владелец | Всё, включая управление участниками и удаление проекта |
| Редактор | Правка параметров, процессов, вариантов и карты, запуск расчётов и симуляций |
| Читатель | Просмотр. Проект читатель не меняет |

Проекты разных пользователей изолированы: пользователь видит только проекты, где он участник.

## Регистрация

По умолчанию регистрация открыта. Если включён режим приглашений, новая учётная запись создаётся только по приглашению с вкладки **Админ / Приглашения**. Как включить режим, написано в разделе [Сопровождение](operations.md).

## Что делает каталог при старте

Файл `data/catalog.csv` загружается, только если таблица решений пуста. Повторный старт файл заново не загружает и строки не удаляет.

Технические характеристики из `data/seeds/robot_specs.json` применяются при каждом старте: существующая строка дополняется, решения не удаляются.

Если в файле каталога один идентификатор встречается дважды, первая строка сохраняет идентификатор, а остальные становятся отдельными решениями с производным идентификатором. Подробности приведены в разделе [Данные и каталог](guide/06-data.md).

Правка робота в разделе **Админ** попадает в следующий расчёт. Сохранённый запуск остаётся на каталоге, с которым его посчитали.
