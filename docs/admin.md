# Каталог и роли

Гость без аккаунта открывает три демо-проекта. Они живут в браузере. Создать свой проект гость не может. Расчёт и экспорт PDF и Excel идут через API и не пишут коммерческие вводы в базу и в журналы.

Аккаунты двух видов: пользователь и администратор. Демо-аккаунты создаются при старте API, если таких адресов ещё нет. Пароли и адреса в README репозитория. До любой внешней выкладки их надо сменить, см. [запуск](operations.md).

У проекта три роли: владелец, редактор, читатель. Читатель проект не меняет.

Вкладка «Админ» есть у администратора: «Каталог», «Приглашения», «Журнал».

## Каталог при старте

CSV из `data/catalog.csv` загружается только если таблица решений пустая. Повторный старт файл заново не заливает и строки не стирает.

ТТХ из `data/seeds/robot_specs.json` обновляются при каждом старте: существующая строка дополняется, решения не удаляются.

Если в CSV один и тот же id встречается дважды, первая строка сохраняет id, остальные становятся отдельными решениями с производным id. Подробности в `data/seeds/NOTES.md`.

Правка робота в «Админ» попадает в следующий расчёт. Уже сохранённый запуск остаётся на каталоге, с которым его посчитали.

## Загрузка

В «Каталог» есть образец на одного робота (поле в строке) и образец таблицы (робот в строке). Файл сначала показывается как предпросмотр. В каталог он попадает только после подтверждения.

Строка с тем же id обновляет это решение, а не создаёт второе. Строка с ошибкой в поле не применяется.

Если файл сделан из выгрузки каталога, предпросмотр сличает три стороны. Поле, изменённое только в файле, берётся из файла. Поле, изменённое только в каталоге, остаётся как в каталоге. Поле, изменённое и там и там по-разному, конфликт. По умолчанию в конфликте побеждает каталог, пока администратор не выберет файл.

Если файла-основания нет, пустая ячейка не затирает хранимое значение.

Пока предпросмотр открыт, каталог мог измениться. Тогда подтверждение отклоняется. Нужно открыть предпросмотр снова.

Роботов, которых нет в файле таблицы с колонкой id, загрузка сама не удаляет. Их можно отправить в архив. Архив убирает робота из обычного списка, строка остаётся.

Ссылка на фото в файле забирается после сохранения строки.

## Приглашения и журнал

Регистрация по умолчанию открытая. Если включён режим приглашений, новый аккаунт создаётся только по приглашению со вкладки «Приглашения». Как включить режим, написано в [сопровождении](operations.md).

«Журнал» пишет действия с аккаунтами, участниками, проектами и каталогом. Правки полей проекта туда не попадают: они хранятся как операции проекта.
