# Глоссарий

| Термин | Определение |
|---|---|
| AMR (Autonomous Mobile Robot) | Автономный мобильный робот. Ездит по складу без магнитных лент и рельсов, ориентируясь по датчикам и карте |
| CAPEX | Капитальные затраты на приобретение и внедрение решения: оборудование, лицензии, монтаж, базовая интеграция |
| ERP | Система планирования ресурсов предприятия |
| FMR (Forklift Mobile Robot) | Автономный вилочный погрузчик или штабелёр |
| IRR | Внутренняя норма доходности: ставка дисконтирования, при которой NPV равна нулю |
| NPV | Чистая приведённая стоимость: сумма денежных потоков, приведённых к году 0 по ставке дисконтирования |
| OPEX | Операционные затраты на эксплуатацию: обслуживание, аренда, расходные материалы, энергия, сервисные контракты |
| RaaS (Robot as a Service) | Аренда роботов с платой за использование, без покупки оборудования |
| ROI | Отношение накопленного эффекта за период к инвестициям, в процентах |
| SKU | Единица номенклатуры товара |
| SLA | Соглашение об уровне обслуживания. В симуляции: допустимая доля заданий, выполненных с нарушением срока |
| TCO | Совокупная стоимость владения: CAPEX плюс операционные затраты за горизонт с учётом замен |
| WMS | Система управления складом |
| БАС | Беспилотная авиационная система |
| БРС | Беспилотная роботизированная система |
| Вариант | Состав флота роботов и способ оплаты в проекте |
| Вердикт | Результат подбора для одной модели: рекомендован, требует проверки или не подходит |
| Горизонт | Срок расчёта экономики в годах |
| Демо | Готовый проект, который открывается без входа |
| Запуск | Неизменяемая запись об одном расчёте или одной симуляции |
| Набор допущений | Именованный набор значений, которые заменяют нормативы в расчёте проекта |
| Норматив | Значение по умолчанию, которое модель берёт, когда оно не задано в проекте или в карточке робота |
| Окупаемость простая | Момент, когда накопленный денежный поток достигает нуля. Ставка дисконтирования на неё не влияет |
| Оценка | Число от 0 до 1, которым подбор упорядочивает модели с одним вердиктом |
| Сверка | Сравнение производительности из симуляции с производительностью в экономике. Расхождение больше 15% поднимает предупреждение |
| Сценарий | Один из трёх способов сравнения: база, покупка, RaaS |
| ТТХ | Технические характеристики робота |
| Флот | Набор роботов варианта |
| Чувствительность | Изменение результата при изменении цены оборудования, объёма операций или фонда оплаты труда |
