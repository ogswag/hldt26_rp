# Переменные окружения

Сервер API читает настройки из переменных окружения. Пример значений для локального запуска лежит в файле `.env.example`. Секреты в репозиторий не кладут.

## База данных и сеть

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `DATABASE_URL` | нет | Строка подключения к Postgres. Обязательна |
| `API_PORT` | `8080` | Порт API |
| `PGPOOL_MAX_CONNS` | `10` | Размер пула соединений |
| `PUBLIC_ORIGIN` | `http://localhost` | Адрес сайта для проверки заголовка `Origin` у изменяющих запросов |
| `ENGINE_DIR` | `/engine` | Каталог с `engine.wasm` и `wasm_exec.js`, которые API отдаёт браузеру |

## Сессии и безопасность

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `COOKIE_SECURE` | `true` | `true`: cookie `__Host-session` только по HTTPS. `false` только для локальной работы, тогда cookie называется `session` |
| `SESSION_IDLE_HOURS` | `168` | Сессия без запросов заканчивается через столько часов (1-8760) |
| `SESSION_MAX_DAYS` | `30` | Предельный срок сессии в днях (1-365) |
| `BCRYPT_COST` | `10` | Стоимость хэширования паролей: 10, 11 или 12 |
| `REGISTRATION_MODE` | `open` | `open`: регистрация открыта. `invite`: только по приглашению |
| `APP_ENV` | `local` | Значение `local` открывает `GET /api/dev/outbox` для просмотра писем. На выкладке задайте другое |

## Демонстрационные учётные записи

| Переменная | Назначение |
|---|---|
| `DEMO_USER_EMAIL` | Адрес демо-пользователя, по умолчанию `user@demo.local` |
| `DEMO_USER_PASSWORD` | Пароль демо-пользователя |
| `DEMO_ADMIN_EMAIL` | Адрес демо-администратора, по умолчанию `admin@demo.local` |
| `DEMO_ADMIN_PASSWORD` | Пароль демо-администратора |

## Каталог

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `CATALOG_CSV` | `/data/catalog.csv` | Файл для первой загрузки каталога |
| `CATALOG_SPECS` | `/data/seeds/robot_specs.json` | Файл с ТТХ роботов, применяется при каждом старте |

## Симуляция и хранение

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `SIM_WORKERS` | `2` | Число обработчиков заданий симуляции в процессе API (1-8) |
| `SIM_JOB_TIMEOUT_MIN` | `10` | Предел времени одного задания в минутах (1-60) |
| `SIM_MAX_ACTIVE_PER_USER` | `3` | Активных заданий на пользователя (1-20) |
| `SIM_LOG_RETENTION_DAYS` | `90` | Срок хранения журнала событий (1-3650) |
| `TRASH_RETENTION_DAYS` | `30` | Сколько дней удалённый проект лежит в корзине (1-3650) |

## Почта

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `MAIL_MODE` | `capture` | `capture`: письма остаются в базе и наружу не уходят. `smtp`: отправка через `SMTP_HOST` |
| `MAIL_FROM` | `no-reply@localhost` | Адрес отправителя |
| `SMTP_HOST` | нет | Сервер SMTP. Обязателен при `MAIL_MODE=smtp` |
| `SMTP_PORT` | `587` | Порт SMTP (STARTTLS) |
| `SMTP_USER`, `SMTP_PASSWORD` | нет | Учётные данные SMTP |

## Переменные Docker Compose

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `WEB_PORT` | `80` | Порт интерфейса на хосте |
| `API_HOST_PORT` | `8080` | Порт API на хосте |
| `COOKIE_SECURE`, `PUBLIC_ORIGIN`, `APP_ENV`, `MAIL_MODE`, `MAIL_FROM`, `REGISTRATION_MODE` | см. выше | Передаются в контейнер API. В Compose для `COOKIE_SECURE` по умолчанию `false` |
