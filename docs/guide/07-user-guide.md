# Руководство пользователя

Чтобы открыть демо, нажмите **Демо Склад** на стартовой странице. Чтобы создать проект, войдите и нажмите **Новый проект**.

Заполните подвкладки **Объекта**. Поля сохраняются сами. Пустое поле с «?» про «по нормативу» на **Допущениях** берёт норматив, это не «нет данных».

Чтобы выбрать робота, откройте **Роботы** и нажмите **Выбрать**. Если подбор исключил робота, меню предупредит: вариант посчитается с риском.

Чтобы пересчитать, откройте **Расчёт**. Страница считает сама после правок. На **Итоге** смотрите окупаемость и состав. **Формулы и источники** показывают проверку симуляцией.

Чтобы прогнать карту, откройте **Симуляцию**, выберите вариант, нажмите **Запустить симуляцию**. Чтобы подобрать число роботов, нажмите **Подобрать**, затем **Взять N в вариант**.

Чтобы выгрузить отчёт, откройте **Экспорт** и скачайте PDF или XLSX. Оговорка в отчёте: результат предварительный и требует обследования объекта.
