# Архитектура

Компоненты: один процесс API на Go, статическое веб-приложение, Postgres. Очередь симуляции живёт в том же процессе.

Данные проекта меняются только операциями: `POST /api/projects/{id}/transactions`. Отдельных PUT для содержимого проекта нет.

Расчёт, подбор и симуляция на карте считаются одним ядром. Сервер и браузер вызывают один код. Браузерное ядро: `engine-wasm`, файлы с `/api/engine/`.

Каталог живой. Каждый запуск записывает `catalog_content_sha256` и `norms_sha256`. Нормативы не входят в хеш черновика проекта.

API описан в `api/openapi.yaml`.
