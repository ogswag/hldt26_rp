# Подбор

Правила жёсткие: грузоподъёмность, габариты, температура, проход. Робот, который не проходит, получает статус «не подходит».

Если ключевое поле ТТХ пустое, статус «требует проверки». Такой робот можно взять в вариант: расчёт покажет предупреждение.

Ранжирование: сначала вердикт, затем окупаемость. Предложение на «Роботах» совпадает со случаем «этот робот один в варианте».

Кнопка «Выбрать» записывает именно этот случай в вариант.
