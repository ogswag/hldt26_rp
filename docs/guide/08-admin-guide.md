# Руководство администратора

Вкладка **Админ** видна только роли администратора.

**Каталог**: правьте робота в оверлее, загружайте таблицу, архивируйте вместо удаления.

**Нормативы**: доли и ставки модели. Пустые поля наборов допущений берут эти числа. НДС и ставка дисконтирования новых наборов тоже. Запись попадает в журнал как «Нормативы изменены».

**Приглашения**: письмо со ссылкой. Можно привязать проект и роль.

**Журнал**: кто менял каталог, приглашения, нормативы и состав проектов. Содержимое проекта здесь не пишется: оно в операциях проекта.
