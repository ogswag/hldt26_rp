# Ограничения и план

Симуляция на карте есть только у склада. Аэропорт и больница получают быструю проверку без карты.

Отказы роботов не моделируются. Диспетчеризация: FIFO, ближайший, приоритет SLA.

Интеграции с WMS, ERP, 1С и мониторингом в поставке нет. Каталог и параметры загружаются файлом. Обмен с внешними системами: выгрузка PDF и XLSX, API расчёта. План: коннекторы к WMS для спроса, к ERP и 1С для цен и ФОТ, к мониторингу для фактической доступности.

Не сделано: 3D, ML-ранжирование, разбор сайтов поставщиков, живой обмен с учётными системами.

Посев ТТХ не обновляет уже заполненную базу.
