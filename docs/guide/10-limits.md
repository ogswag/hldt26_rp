# Ограничения и план

## Известные ограничения

### Функции

- Симуляция на карте есть только у склада. Для аэропорта и больницы выполняется быстрая проверка без карты.
- Отказы роботов не моделируются.
- Правила диспетчеризации: по порядку поступления, ближайший робот, приоритет SLA.
- Расчёт идёт на собственные средства. Кредит и лизинг не моделируются.
- Цены постоянные, инфляции и роста зарплат нет, остаточная стоимость оборудования не учитывается.
- Ранжирование считается по правилам, а не обучается на данных.

### Данные

- Технические характеристики найдены примерно у 55 из 187 роботов каталога. У остальных поля пусты, подбор отмечает их как «требует проверки».
- Радиус разворота не найден ни у одного робота. Время зарядки у части моделей пустое.
- Срок службы и годовая доля сервиса не найдены ни в одном источнике, расчёт подставляет допущение.
- Посев характеристик не обновляет уже заполненную базу. Новые значения видны на чистой базе или после правки в редакторе администратора.

### Эксплуатация

- В составе Compose нет шифрования: HTTPS настраивается на внешнем прокси.
- Нагрузочный тест на 50 одновременных пользователей не проводился.
- Готового развёрнутого стенда в сети нет, платформа запускается командой `docker compose up`.

### Интеграции

Интеграций с WMS, ERP, 1С и системами мониторинга в поставке нет. Каталог и параметры загружаются файлами. Обмен с внешними системами идёт через выгрузку PDF и XLSX и через API расчёта.

## План развития

| Направление | Что планируется |
|---|---|
| Интеграции | Коннектор к WMS для получения спроса, к ERP и 1С для цен и фонда оплаты труда, к системам мониторинга для фактической доступности роботов |
| Каталог | Разбор сайтов поставщиков, плановое обновление каталога, расширение набора ТТХ |
| Модели | Симуляция на карте для аэропорта и больницы, отказы и обслуживание роботов, встречное движение на двухполосных участках |
| Экономика | Заёмное финансирование, налог на прибыль, инфляция |
| Ранжирование | Оптимизация и машинное обучение, когда накопятся данные внедрений |
| Визуализация | Трёхмерное представление объекта |
| Роли | Роль вендора |
