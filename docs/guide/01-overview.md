# Обзор возможностей

Платформа считает экономику внедрения роботов на объектах трёх типов: склад, аэропорт и медицинское учреждение. Для склада она дополнительно имитирует работу роботов на плане и проверяет, что заявленная производительность достижима.

## Основные понятия

Полный список терминов приведён в [глоссарии](../reference/glossary.md).

- **Проект.** Данные об одном объекте: параметры, процессы, карта, варианты и результаты расчётов.
- **Вариант.** Состав флота роботов и способ оплаты. В проекте до шести вариантов, по умолчанию создаются три.
- **Сценарий.** Способ сравнения. Платформа считает три сценария: «База» (текущий процесс без роботов), «Покупка» (оборудование приобретается) и «RaaS» (оборудование арендуется).
- **Запуск.** Неизменяемая запись об одном расчёте или одной симуляции. Запуск хранит входные данные, версии моделей и контрольные суммы, поэтому результат можно воспроизвести.
- **Демо.** Готовый проект, который открывается без входа. Для каждого типа объекта есть свой демо-проект.

## Сценарии использования

1. Гость открывает демо, меняет параметры и смотрит страницу «Итог». Проекты гость не создаёт, введённые данные остаются в его браузере.
2. Пользователь создаёт проект, заполняет параметры объекта и процессы, выбирает роботов, получает расчёт и выгружает отчёт в форматах PDF и XLSX.
3. Администратор ведёт каталог роботов, задаёт нормативы расчёта, приглашает пользователей и просматривает журнал действий.

## Путь пользователя

| Шаг | Вкладка | Результат |
|---|---|---|
| 1. Выбор объекта | Стартовая страница | Создан проект или открыто демо склада, аэропорта или больницы |
| 2. Параметры | **Объект** | Заполнены параметры объекта, процессы и карта склада |
| 3. Подбор | **Роботы** | Получен список моделей с вердиктом и объяснением, роботы выбраны в варианты |
| 4. Расчёт | **Расчёт / Итог** | Рассчитаны CAPEX, OPEX, эффект, окупаемость и ROI для трёх сценариев |
| 5. Допущения | **Расчёт / Допущения** | Изменены ключевые допущения, результат пересчитан |
| 6. Симуляция | **Расчёт / Симуляция** | Проверена производительность флота на карте склада |
| 7. Экспорт | **Расчёт / Экспорт** | Скачаны отчёты в форматах PDF и XLSX |

## Степень готовности

| Функция | Готовность | Комментарий |
|---|---|---|
| Подбор по техническим характеристикам | Полностью | Жёсткие проверки, оценка с весами, объяснение для каждой модели |
| Экономическая модель | Полностью | Три сценария, денежный поток по годам, чувствительность, нормативы |
| Отчёты PDF и XLSX | Полностью | Отчёт строится из снимка запуска |
| Симуляция на карте склада | Полностью | Событийная модель, подбор числа роботов прогонами |
| Проверка для аэропорта и больницы | Частично | Быстрая проверка без карты, событийной симуляции нет |
| Каталог роботов | Частично | Технические характеристики заполнены не у всех моделей |
| Интеграции с WMS, ERP и 1С | Не сделано | Описаны как план развития |
| 3D и ранжирование методами машинного обучения | Не сделано | Не входят в поставку |

Ограничения и план развития описаны в разделе [Ограничения и план](10-limits.md).
