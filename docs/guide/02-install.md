# Развёртывание

Чтобы поднять платформу на чистой машине, выполните `docker compose up --build` в корне репозитория. Compose поднимает API, веб и Postgres.

Переменные задаются в `.env`. Пароли не коммитьте. Нужны как минимум `DATABASE_URL`, `COOKIE_SECURE`, `PUBLIC_ORIGIN`.

Демо-аккаунты после посева: смотрите `README.md` репозитория. Гость не создаёт проекты: ему доступны «Демо Склад», «Демо Аэропорт» и «Демо Больница» в браузере.

Проверка: откройте главную, войдите, откройте демо склада, дождитесь «Итога». Если каталог пуст, посев не прошёл: выполните `docker compose down -v` и поднимите снова.

Посев ТТХ не перезаписывает значения, которые правил администратор. Новые числа из `data/seeds/robot_specs.json` видны только на чистой базе.
