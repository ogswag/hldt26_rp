# Проверка для жюри

Войдите гостем или откройте демо без входа.

1. Откройте **Демо Склад**. Ожидание: три варианта с роботами, карта заполнена.
2. Откройте **Роботы**, выберите робота со статусом «не подходит». Ожидание: предупреждение в меню, риск на **Итоге**.
3. Откройте **Расчёт / Итог**. Ожидание: таблица сценариев, строка «Зарядных станций».
4. Откройте чувствительность. Ожидание: блоки по трём вариантам, не пустые строки.
5. Запустите симуляцию варианта 2. Ожидание: таблица «Проверка симуляцией» обновляется без пересчёта экономики. Правка другого варианта не делает сверку устаревшей.
6. Нажмите **Подобрать**, затем **Взять N**. Ожидание: **Итог** пересчитан, сверка варианта действующая.
7. **Сохранить кадр** и **Показатели CSV**. Ожидание: PNG и CSV скачиваются.
8. На **Допущениях** измените загрузку. Ожидание: другой размер флота.
9. Администратор: **Нормативы**, смените ставку, создайте набор. Ожидание: новый набор берёт ставку.
10. Выгрузите PDF и XLSX. Ожидание: параметры объекта, источники, дата расчёта, оговорка, зарядки, лист «Чувствительность».
