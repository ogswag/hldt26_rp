# Проверка демонстрационного сценария

Этот сценарий позволяет за несколько минут убедиться, что основные функции платформы работают. Сценарий выполняется на проекте «Демо Склад» без входа в систему. Шаг 9 требует учётной записи администратора.

## Перед началом

Запустите платформу по инструкции из раздела [Развёртывание](02-install.md) и откройте в браузере http://localhost.

## Шаги проверки

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | На стартовой странице нажмите **Демо Склад** | Открыт проект с тремя вариантами, в каждом есть роботы. Карта склада заполнена |
| 2 | Откройте вкладку **Роботы** и выберите робота со статусом «не подходит» | В меню появляется предупреждение. На странице «Итог» показан риск |
| 3 | Откройте **Расчёт / Итог** | Показана таблица трёх сценариев. В таблице есть строка «Зарядных станций» |
| 4 | Найдите на вкладке **Расчёт** раздел «Чувствительность ±20%» | Для каждого варианта показан отдельный блок с изменением цены, объёма и фонда оплаты труда. Пустых строк нет |
| 5 | Откройте **Симуляцию**, выберите вариант 2 и нажмите **Запустить симуляцию** | Таблица «Проверка симуляцией» обновляется, экономика не пересчитывается. Правка другого варианта не делает эту проверку устаревшей |
| 6 | Нажмите **Подобрать**, затем **Взять N в вариант** | Число роботов записано в вариант, страница «Итог» пересчитана, проверка симуляцией для варианта действует |
| 7 | В симуляции нажмите **Сохранить кадр** и **Показатели CSV** | Скачаны файл PNG с кадром и файл CSV с показателями |
| 8 | На странице **Допущения** измените коэффициент загрузки | Размер флота изменился, результат пересчитан |
| 9 | Войдите как администратор, откройте **Админ / Нормативы**, измените ставку и создайте набор допущений | Новый набор использует изменённую ставку |
| 10 | Откройте **Экспорт** и скачайте файлы PDF и XLSX | В отчётах есть параметры объекта, источники, дата расчёта, оговорка о предварительном характере оценки, зарядные станции и лист «Чувствительность» |

## Что делать при расхождении

- Если на шаге 1 нет вариантов с роботами или карта пуста, проверьте, что каталог загружён: откройте вкладку **Роботы**, в списке должны быть модели. Если список пуст, выполните сброс данных по инструкции из раздела [Развёртывание](02-install.md#сброс-данных).
- Если на шаге 5 запуск симуляции не начинается, проверьте, что в проекте нет ошибок карты. Запуск с ошибками карты запрещён.
- Если на шаге 10 отчёт не скачивается с кодом 409, черновик проекта изменился после последнего расчёта. Дождитесь пересчёта на странице «Итог» и повторите выгрузку.
