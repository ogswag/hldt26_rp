# Данные

Каталог загружается таблицей на «Админ / Каталог». Дубликаты UUID в исходном CSV: это одно изделие в разных отраслях, не второй робот.

ТТХ сеются из `data/seeds/robot_specs.json`. Значение вносится только со страницы, где оно названо для модели. Спорное значение не вносится, пробел объясняется в `data/seeds/NOTES.md`.

Посев не перезаписывает значения и пропускает роботов, которых правил администратор. Новые ТТХ полностью видны только на чистой базе: `docker compose down -v`.

Параметры объекта: XLSX-шаблон на вкладке объекта. «Неизвестно» это пустое поле.
