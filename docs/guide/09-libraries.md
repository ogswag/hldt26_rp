# Библиотеки и данные

Сервер: Go, chi, pgx, sqlc, excelize.

Веб: React, Vite, TypeScript, TanStack Query, Konva.

Шрифты: IBM Plex Sans, OFL. Иконки: Tabler Icons, MIT, скопированы в `web/src/ui/icons.tsx`.

Каталог организаторов: `Датасет/catalog_export_v4.csv`. Примеры ТТХ: `Датасет/Примеры_решений_типы_объектов.docx`. Параметры объектов: `Датасет/Датасеты_хакатон.xlsx`.

Ядро в браузере собирается из `api/cmd/engine-wasm`.
