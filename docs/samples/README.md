# Образцы отчёта

Чтобы получить PDF и XLSX заново, откройте **Демо Склад**, дождитесь **Итога**, перейдите на **Экспорт** и скачайте оба файла. Положите их в эту папку как `demo-sklad.pdf` и `demo-sklad.xlsx`.

Отчёт содержит дату расчёта, дату отчёта, параметры объекта, источники, оговорку про обследование, зарядки и чувствительность без NPV, IRR и ROI на листе XLSX.
