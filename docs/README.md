# Платформа подбора роботизированных решений

Платформа считает, окупится ли робот на складе, в аэропорту или в больнице, и для склада показывает, где на плане узкое место. Цифры выходят из введённых цен, скоростей и спроса. Обследование объекта они не заменяют.

- [Как читать результат](model.md): что означают сценарии, отчёт и предупреждения.
- [Каталог и роли](admin.md): кто что может и как обновлять роботов.
- [Запуск и сопровождение](operations.md): пароли, копия базы, миграции, сбой.
- [Как менять код](development.md): куда править, чтобы расчёт и интерфейс не разъехались.

Команды запуска и список переменных окружения лежат в [README репозитория](../README.md).
