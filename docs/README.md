# Платформа подбора роботизированных решений

Платформа оценивает, окупится ли внедрение роботов на складе, в аэропорту или в медицинском учреждении. Она подбирает подходящие модели из каталога, считает экономику покупки и аренды и сверяет расчёт с имитацией работы роботов на плане склада.

Результат платформы предварительный. Он помогает быстро проверить гипотезу и сравнить варианты. Обследование объекта и полное технико-экономическое обоснование он не заменяет.

- **Начало работы:** обзор, развёртывание, проверка демо.
